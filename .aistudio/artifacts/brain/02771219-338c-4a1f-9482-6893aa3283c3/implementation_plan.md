# ระบบตรวจและประเมินผลรูบริกแยกรายไฟล์ (Form B: Per-File Rubric Evaluation)

## สรุปการพัฒนาระบบตามที่ท่านเลือก (แบบ B)
กรณีที่ครูส่งงานที่มีหลายไฟล์แนบมาพร้อมกันใน 1 คำขอส่ง กรรมการ/ผู้ตรวจสามารถ:

1. **ตรวจรูบริกและตัดสินผลแยกรายไฟล์ (Per-File Evaluation)**:
   - **แท็บสลับตรวจแต่ละไฟล์**: มีปุ่มแท็บระบุลำดับไฟล์ ชื่อไฟล์ พร้อมป้ายสถานะ `✓ ผ่าน (XX%)` หรือ `⚠️ ตีกลับ (XX%)`
   - **เลือกผลตรวจเฉพาะไฟล์**:
     - `✅ ให้ผ่านไฟล์นี้ (Approved)`
     - `⚠️ ตีกลับให้แก้ไฟล์นี้ (Needs Revision)`
   - **ประเมินรูบริก 5 ด้านเฉพาะไฟล์นี้ (100%)**: สามารถคลิกให้คะแนน 1-5 ดาวในแต่ละด้านของไฟล์นั้นๆ ระบบคำนวณ % คะแนนของไฟล์นั้นให้ทันที
   - **ข้อเสนอแนะเฉพาะไฟล์**: มีช่องกรอกข้อเสนอแนะและปุ่มคีย์ลัดสำหรับไฟล์นั้นโดยเฉพาะ
   - **ปุ่มด่วน (Batch Actions)**: `[✨ ให้ผ่านทุกไฟล์ (100%)]` และ `[⚠️ ตีกลับทุกไฟล์]` สำหรับการตรวจเร็ว

2. **ตารางสรุปผลการตรวจทุกไฟล์ (All-Files Overview Table)**:
   - แสดงรายชื่อทุกไฟล์ สถานะ คะแนนรูบริก และข้อเสนอแนะเฉพาะไฟล์
   - **สรุปผลภาพรวมอัตโนมัติ**: หากมีไฟล์ใดไฟล์หนึ่งถูกตีกลับ ระบบจะแนะนำสถานะภาพรวมเป็น `ส่งกลับเพื่อปรับปรุงแก้ไข` ทันที แต่หากผ่านครบทุกไฟล์จะแนะนำเป็น `อนุมัติ`

3. **การแสดงผลทางฝั่งคุณครู**:
   - **การ์ดแผนการจัดการเรียนรู้ (LessonPlanCard)**: แสดงชิปผลตรวจแยกรายไฟล์ และปุ่มกดขยายดูรายละเอียดคะแนนและข้อเสนอแนะของแต่ละไฟล์
   - **หน้าต่างส่งแก้ไขใหม่ (ResubmitPlanModal)**: แสดงผลตรวจแยกรายไฟล์อย่างชัดเจน เพื่อให้ครูทราบทันทีว่าไฟล์ไหนผ่านแล้ว และไฟล์ไหนที่ต้องนำไปปรับปรุงแก้ไขก่อนส่งใหม่
